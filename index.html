ALIENS: USCMC

COLONIAL MARINES // TACTICAL CONTROL

A colony has gone silent. You sit at the control deck of a ship in orbit and guide a squad of four marines through the complex below, seeing only what their helmet cameras show, a tactical map with sonar and their vitals. Find the nest, kill what lives in it and bring them back alive.

PLAY

AI AGENT OPTIONAL

The game plays fine on its own: you give orders with the console buttons and the soldiers call in contacts themselves. You can also link an AI agent running on your own computer. The agent then commands and voices the whole squad: you talk to the marines in plain language over the radio ("Drake, hold the corridor", "sneak into the medlab, don't shoot") and they answer in their own voices.

The agent talks to the game through a small bridge program: one file, no installs, needs Node.js 18 or newer. It only listens on your own machine (127.0.0.1) and only accepts this game's address.

⚙ AGENT SETUP

LINKING CLAUDE CODE

  1. Open a terminal and start Claude Code. To skip the approval prompt on every radio call, start it with the bridge pre-approved: 
    claude --allowedTools "Bash(node ~/.directive937/bridge.mjs:*)"
  2. Open ⚙ AGENT SETUP, press COPY and paste the prompt into Claude Code. It downloads the bridge, starts it and prints a banner when it's ready.
  3. Press PLAY, then press LINK AGENT in the top bar. If the browser asks to let the page reach apps on your device, allow it. The top bar shows AGENT: STANDING BY when the agent is listening.
  4. Type your orders in the comms box. To finish, tell the agent to stop; it shuts the bridge down with node ~/.directive937/bridge.mjs stop.

OTHER AGENTS

TERMINAL AGENTS

Any coding agent that can run shell commands (Codex CLI, Gemini CLI and the like) can use the same prompt from AGENT SETUP. Let it run node ~/.directive937/bridge.mjs without asking each time, so the radio loop doesn't stall.

MCP CLIENTS

Agents that use MCP tools can run the bridge as an MCP server instead (the bridge/ folder): same game, tools instead of commands. For Claude Code:

cd bridge && npm install
claude mcp add directive937 \
  -e DIRECTIVE937_ORIGINS=https://your-game-server \
  -- node /full/path/bridge/index.js
