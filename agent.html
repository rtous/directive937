◤ ALIENS: USCMC // AGENT SETUP

WHAT THIS DOES

Your squad is commanded and voiced by an AI agent running on your own computer, such as Claude Code. Paste the prompt below into the agent. It downloads a small bridge program (one file, no installs), starts it, and then listens for your radio messages: it gives the soldiers orders and answers as them.

1 // PASTE THIS INTO CLAUDE CODE

Loading…

2 // APPROVE THE BRIDGE COMMANDS

Claude Code asks before running commands. Approve the download once, and for node ~/.directive937/bridge.mjs choose "Yes, and don't ask again" so the radio loop runs smoothly.

Or start Claude Code with the bridge pre-approved:

claude --allowedTools "Bash(node ~/.directive937/bridge.mjs:*)"

3 // PLAY

Once the agent says the bridge is ready, press LINK AGENT in the game's top bar. Your browser may ask to let the page reach apps on your device: allow it (the bridge only runs on your own machine). The game remembers this, so a reload links again by itself.

Keep the game open in this browser. The top bar shows AGENT: STANDING BY when the agent is listening. Pick who to talk to in the comms box (ALL or one soldier) and type your orders. To finish, tell the agent to stop the loop and run node ~/.directive937/bridge.mjs stop.

WHAT GETS INSTALLED

One file, bridge.mjs, saved to ~/.directive937/. It needs Node.js 18 or newer and only listens on your own machine (127.0.0.1). It accepts connections from this game's address only, and the agent's commands are protected by a key stored next to it. You can read the file before running it: bridge.mjs.
